## 5. 典型案例

### 案例 1（第 2–5 轮修正，Complex.js / `mutant-f7d009c`，第 6 轮成功）

变异体把 `abs()` 中的阈值比较 `< 3000` 改成了 `<= 3000`，只影响 `b === 3000` 这一个边界点。前几轮模型给出的测试要么在原程序就失败，要么在两个版本都能通过。最终成功的测试精准选用了 `new Complex(1.0000000000000002, 3000)`，先断言两种计算方式在该输入下确实不同，再断言实际返回值等于原分支的算法结果——这是典型把“边界值分析”应用到浮点比较上的成功修正。

### 案例 2（详细反馈的价值：delta / `mutant-bfe4f6d`，第 10 轮成功）

该样本跑了满 10 轮才成功，是耗时最长的样本之一。前 9 轮均在 `fail_fail_on_original` 与 `fail_pass_on_mutation` 之间反复，最终一轮通过 `Delta.compose` 构造了首元素为 embed retain 的边界组合并杀掉变异。这类样本说明：**部分行为差异需要模型多轮试探才能定位**，C 组 10 次的预算并非浪费。

### 案例 3（无效测试：Complex.js / `mutant-f9e9146`，第 1 轮“成功”）

```
expect((Complex as any).__esModule).toBe(true);
```

该测试没有调用任何 Complex 方法，只断言了模块系统标记 `__esModule`。它能让变异分支失败，但检查的不是外部可观察行为，**判为无效杀死**。此案例与论文 Fig.6 的作弊例子同源，是本次唯一的 invalid_kill_only。

### 案例 4（负控验证：10 个等价变异体全部未被误杀）

10 个等价变异体（Complex.js、countries-and-timezones、crawler-url-parser×3、delta×2、plural、pull-stream、spacl-core）在 10 轮内均未被任何测试杀死，**误杀率 0/10**。说明模型没有依赖随机或碰巧的方式“杀死”行为未变的变异体，对应论文最关心的假阳性问题。

## 6. 人工复核方法

82 个有效杀死 + 1 个无效杀的判定基于以下标准（逐条查看 `testCase.test.ts`）：

1. 测试是否**真的调用了被测函数**；
2. 断言对象是否为**返回值、抛出的异常、副作用或产物内容**（外部可观察行为）；
3. 是否通过 `toString()`、`__esModule`、读取源码文本等**非行为信号**区分版本。

83 个样例已按上述规则逐一判断，判断依据写入 `mutant_summary.csv` 的 `notes` 字段。

## 7. 异常情况与处理

| 现象                                                          | 处理                                                   |
| ----------------------------------------------------------- | ---------------------------------------------------- |
| 2026-11-11 22:23 第一次 q 批次中断：`TypeError: fetch failed`（网络断连） | 数据保留，重新开跑新目录                                         |

| 批量运行时日志文件被前一窗口占用（`out-file` 冲突）                             | 关闭旧窗口后重跑                                             |
| 部分样本 `attempt_10` 跑满未成功                                     | 按官方规则计入 `fail_*` 类别，保留原始产物，未删除                       |

**未删除任何失败样本**：所有 `no_result` / `fail_*` 记录均保留在 `calls.csv` 与 `artifacts/` 中。

## 8. 威胁与局限

1. **样本非随机**：100 个样本为精选诊断样本，q 与 Complex.js 占 54%，汇总数字受这两个项目主导，不能外推总体成功率；
2. **模型档位差异**：DeepSeek-flash 为轻量模型，与论文 Claude-Sonnet 档不可等同比较；
3. **人工复核为单人**：论文由两位作者独立标注并报告 Cohen's κ；本组由单人复核，虽逐条记录依据，仍存在主观性；
4. **非思考模式**：通过本地补丁强制关闭 thinking，与 API 默认行为不同，已在 `run_config.json` 的 `runner_commit` 中注明。
