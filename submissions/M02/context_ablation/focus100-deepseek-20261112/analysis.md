# B 组：缩减上下文实验结果

100 个样本均有选定运行结果；其中 11 个因首轮 Jest 超时而单独重跑，本表使用重跑结果。工具自动判定 successful 为 71 个，未自动判定杀死为 29 个。

71 个自动成功中，68 个最终轮日志未出现 Jest 测试超时；另外 3 个变异程序测试超时，原程序测试通过，是否反映稳定的程序行为差异仍需核实。29 个未自动成功中，3 个最终轮原程序测试超时，其余 26 个最终轮未记录 Jest 超时。自动成功不等于已人工核实的行为差异，`valid_kill` 暂为 unknown。

按用户口径，同一测试在原程序与变异体上行为不同可计为杀死；应排除测试或环境故障后再确认。等价标签尚未引入，不能计算非等价样本有效杀死率，也不能仅凭自动数与对照组推断消融效应。

运行在 Windows Node 24 而非官方 Linux Node 20；两种上下文分别为函数或顶层代码单元。CSV 轮次及 token 是选定运行的累计值，不包含早期被中断运行或其他重跑的额外消耗，不可当作账户总费用。`sample_id`、费用、人工标签和人工复核结果尚无可信数据，保留空白或 unknown。

依据用户要求，逐轮 Prompt、对话、日志、原始 reports 和 calls 过程记录仅保存在本地，未推送；结果表和配置可供复核时定位。
